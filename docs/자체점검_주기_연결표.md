## 동작 요약

1. "월간 자체점검"으로 시작하면, 그 설비의 지난 점검 기록(`checkedItems`, 제출 시각)을 보고 위 56개 중 주기가 돌아온 항목만 깐다.
2. 한 번도 점검하지 않은 항목은 "기한 지남"으로 맨 앞에 온다. (처음 점검하는 설비는 56개 전부)
3. 지난 점검에서 n개월이 지났을 때: n > 주기 → 기한 지남, n = 주기 → 이번 달, n < 주기 → 대상 아님.
4. 대상이 아닌 항목도 말하면 그 자리에서 추가되어 기록된다.
